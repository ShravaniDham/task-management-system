# User Stories

Format: *As a [user], I want [goal], so that [benefit].*

| ID | Story | Priority | Points |
|----|-------|----------|--------|
| US-1 | As a user, I want to add a task with a title, description, status and priority, so that I can record my work. | High | 5 |
| US-2 | As a user, I want to view all tasks and filter them by status or title, so that I can find what to work on. | High | 3 |
| US-3 | As a user, I want to update a task, so that I can correct details or mark it In Progress / Done. | High | 5 |
| US-4 | As a user, I want to delete a task, so that my list does not contain tasks I no longer need. | Medium | 3 |
| US-5 | As a team, we want an automated pipeline and a metrics dashboard, so that every change is built, tested, checked and deployed, and progress is visible. | High | 8 |
